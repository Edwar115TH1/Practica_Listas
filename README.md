Una tienda necesita organizar las ventas realizadas durante el día. Actualmente, el administrador registra la información manualmente, lo que dificulta identificar las ventas más altas, corregir registros equivocados, consultar las compras de un cliente y conocer el dinero recaudado.

Se solicita desarrollar una aplicación que permita administrar las ventas de la tienda y generar información útil para el administrador.

Información que debe manejar cada venta
Cada venta debe almacenar los siguientes datos:

Número de factura.
Nombre del cliente.
Nombre del vendedor.
Valor total de la venta.
Cantidad de productos vendidos.
Estado de la venta: registrada o cancelada.

Funcionalidades solicitadas
Los estudiantes deben desarrollar un menú que permita realizar las siguientes operaciones:

1. Registrar una venta
Solicitar la información de una nueva venta y agregarla a la lista. No se puede registrar otra venta con un número de factura que ya exista.

2. Mostrar las ventas
Presentar todas las ventas registradas, indicando cuáles están activas y cuáles fueron canceladas.

3. Buscar una venta
Consultar una venta mediante su número de factura. Si no existe, informar al usuario.

4. Modificar una venta
Permitir corregir el nombre del cliente, el vendedor, el valor o la cantidad de productos. La factura no debe cambiar de número.

5. Cancelar una venta
Cambiar el estado de una venta a cancelada sin eliminar su registro. Una venta cancelada no debe contabilizarse en los ingresos.

6. Eliminar una venta
Eliminar definitivamente una venta de la lista, previa confirmación del usuario.

7. Generar un informe
Mostrar el total recaudado por las ventas no canceladas, la venta de mayor valor, la venta de menor valor, el promedio de ventas activas y la cantidad de ventas canceladas.
